Whether you are opening your books for the first time or counting down the final days to exam week, **CMA Study Buddy** adapts to how CMA students actually study:

## 🛠️ Tech Stack

### 📱 Android (`CMA Pocket MCQ`)
- **Stack:** Kotlin, Jetpack Compose, Material 3
- **Storage:** Room SQLite + Jetpack DataStore
- **Security:** R8 shrinking & obfuscation, `allowBackup="false"`, zero `INTERNET` permission

### 💻 Windows (`CMA MCQ Buddy`)
- **Stack:** Tauri (Rust) + React + TypeScript
- **Audio:** 100% offline Web Audio API synthesizer
- **Storage:** Local JSON persistence at `%APPDATA%\CMA-MCQ-Buddy\user_data.json`

## 📦 Installation Guide

### Android
1. Download `CMA-Pocket-MCQ-v1.1.0.apk` from [Releases](https://github.com/YOUR_USERNAME/YOUR_REPO/releases/latest).
2. Tap the downloaded `.apk` file to install (enable **"Install unknown apps"** for your browser or file manager if prompted).
3. *(Optional)* To use the floating **CMA-12D** calculator over other apps, grant **"Display over other apps"** when prompted inside the calculator screen.

### Windows
- **Portable:** Download `CMA-MCQ-Buddy-Portable.exe` and double-click to launch—no installation required.
- **Installer:** Download and run `CMA-MCQ-Buddy-Setup-v1.1.0.exe` (or `.msi`).
- *Windows SmartScreen Note:* Because this is a free, independent open release without a paid code-signing certificate, Windows Defender SmartScreen may show a warning on first launch. Click **More info → Run anyway** to open the app.
